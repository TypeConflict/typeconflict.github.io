GitHub Pages

連接 GitHub

使用 GitHub Fine-grained personal access token 直接提交到 TypeConflict/typeconflict.github.io。只需授權此儲存庫的 Contents: Read and write；不需要其他權限。

Token 不會寫進網站程式、localStorage 或 cookie，只保存在本頁記憶體中。關閉或重新整理後須再次輸入。請在自己的裝置操作，避免瀏覽器擴充套件讀取敏感資料。

撰寫內容

每篇僅顯示一張照片。會轉成壓縮 WebP，長邊最多 1800px，刪除 EXIF 等原始相片資訊後存進 GitHub。編輯既有照片時不選新圖就會保留舊照片。

已公開內容

可編輯或刪除已發布內容。更新 GitHub Pages 會有短暫部署延遲。

這是公開可讀的管理頁面，但沒有 Token 就不能發文。原本的本機草稿編輯器仍可使用。
