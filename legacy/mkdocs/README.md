# 舊 MkDocs 網站存檔

此目錄保存改版前的資料，不參與目前 GitHub Pages 根目錄網站的建置。

- `docs/`：原本的 Markdown 筆記與資產，保留原內容。
- `mkdocs.yml`：原本的設定與導覽。
- `site/`：歷史產生的靜態網站，保留供比對；可能與原文版本不同，不是目前網站。

2026-11-24 整理時僅搬移路徑，並移除 macOS `.DS_Store`。舊路徑下的直接連結不再保證可用。

要讓舊筆記出現在現行網站，請挑選內容移入根目錄 `content.json` 的 Blog 或 Notes；不會自動匯入。原本的相對路徑應重新確認。

如需參考舊建置，可在這個目錄以已安裝的 MkDocs／Material 環境本機預覽；不要執行 `mkdocs gh-deploy`，避免覆蓋目前部署。
